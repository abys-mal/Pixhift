# Changelog

## v1.0.0 — 2026-11-24

- Initial release of Pixhift for offline batch image conversion and metadata editing.
- One executable opens the desktop app without arguments and accepts CLI commands for conversion, metadata, format support, and image information.
- Import smartphone HEIC/HEIF and other common formats. Export JPEG, PNG, WebP, AVIF, TIFF, BMP, or GIF.
- Preview batch changes, preserve or edit supported metadata, remove GPS tags, and export processing reports.
